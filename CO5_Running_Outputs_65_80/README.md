# CO5 Running Outputs (Experiments 65–80)

## Run on Windows
1. Install Python 3.10+ and tick **Add Python to PATH**.
2. Extract this folder from the ZIP.
3. Open the folder, click the address bar, type `cmd`, and press Enter.
4. Run:
   ```
   py -m pip install -r requirements.txt
   py run_all.py
   ```
5. Press **Enter** when prompted to run each experiment in order. Charts are saved as PNG files in `outputs`.

The program runs experiments 65–80 sequentially and saves graphs. Some experiments use synthetic/demo data or simplified illustrative proxies rather than fully trained specialized networks/audio recordings. Read the printed note for those experiments.
