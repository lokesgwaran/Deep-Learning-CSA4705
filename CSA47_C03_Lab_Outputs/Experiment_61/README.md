# Experiment 61: LSTM hyperparameter comparison

## Run on Windows
1. Install Python 3.10+ and check **Add Python to PATH**.
2. Open this folder.
3. Double-click `run.bat`.

If libraries are missing, open Command Prompt in this folder and run:
`python -m pip install -r requirements.txt`

Charts (when produced) are saved in the `output` folder. Some TensorFlow experiments load MNIST and need an internet connection the first time.
